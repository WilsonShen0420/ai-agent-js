# 作業 5：向量相似度實驗

> AI Agent 實作工作坊（JavaScript 版）
> 基底分支：`3.1-rag-text-to-vector`

使用 OpenAI Embeddings API 把文字轉成向量，計算不同句子之間的餘弦相似度，並驗證結果是否符合預期。

## 一、測試文字（5 組，每組 3 句）

| 組別 | 句子 |
|---|---|
| 第 1 組：意思相近 | (1) 我喜歡喝紅茶　(2) 紅茶的香氣很迷人　(3) 我每天早上都要喝一杯紅茶 |
| 第 2 組：意思不同 | (1) 高鐵快要進站了　(2) 這部電影很好看　(3) 手機快沒電了 |
| 第 3 組：偷換概念-1（自訂） | (1) 我喜歡喝紅茶　(2) 部門中紅茶的軟體設計能力很厲害　(3) 我每天早上都要喝一杯紅茶 |
| 第 4 組：偷換概念-2（自訂） | (1) 我喜歡喝紅茶　(2) 部門中紅茶的軟體設計能力最厲害　(3) 在我們部門中總共有十位軟體工程師 |
| 第 5 組：主題 vs 情緒（自訂） | (1) 這家餐廳的食物非常美味，我很推薦　(2) 這家餐廳難吃到讓我很後悔　(3) 這場電影非常溫馨感人，我很推薦 |

> 第 3/4 組設計用意：測試 embedding 對於同詞不同概念(偷換概念)是否有區分能力，在測試之前我以為應該是很弱。
> 第 5 組設計用意：前兩句同為「餐廳」主題但情緒相反，第三句為不同主題。
> 觀察 embedding 主要是依「主題」聚類，還是依「情緒」聚類。資料可在 `data/sentence-groups.js` 自行替換。

## 二、檔案結構

```
lib/embeddings.js        呼叫 Embeddings API 取得向量（embed / embedBatch）
lib/similarity.js        餘弦相似度計算（純函式）
data/sentence-groups.js  五組測試文字
main.js                  相似度測試程式（embedding + 兩兩相似度輸出）
test/similarity.test.js  相似度與資料的離線測試
```

對應作業繳交內容：

| 繳交項目 | 檔案 |
|---|---|
| Embeddings 相關程式 | `lib/embeddings.js` |
| 相似度測試程式 | `main.js`、`lib/similarity.js` |

## 三、執行方式

```bash
npm install
cp .env.example .env      # 填入你的 OPENAI_API_KEY
npm start
```

離線驗證相似度計算（不需金鑰）：

```bash
npm test
```

測試涵蓋：相同/正交/相反向量、只看方向、維度檢查、測試資料結構。

## 四、實驗結果與分析

```
第 1 組：意思相近
(1) 我喜歡喝紅茶
(2) 紅茶的香氣很迷人
(3) 我每天早上都要喝一杯紅茶
兩兩相似度：
(1) × (2) = 0.6706
(1) × (3) = 0.7513
(2) × (3) = 0.5313

第 2 組：意思不同
(1) 高鐵快要進站了
(2) 這部電影很好看
(3) 手機快沒電了
兩兩相似度：
(1) × (2) = 0.1827
(1) × (3) = 0.3820
(2) × (3) = 0.2285

第 3 組：偷換概念-1(自訂)
(1) 我喜歡喝紅茶
(2) 部門中紅茶的軟體設計能力很厲害
(3) 我每天早上都要喝一杯紅茶
兩兩相似度：
(1) × (2) = 0.4648
(1) × (3) = 0.7513
(2) × (3) = 0.4133

第 4 組：偷換概念-2(自訂)
(1) 我喜歡喝紅茶
(2) 部門中紅茶的軟體設計能力最厲害
(3) 在我們部門中總共有十位軟體工程師
兩兩相似度：
(1) × (2) = 0.4482
(1) × (3) = 0.1476
(2) × (3) = 0.5250

第 5 組：主題 vs 情緒（自訂）
(1) 這家餐廳的食物非常美味，我很推薦
(2) 這家餐廳難吃到讓我很後悔
(3) 這場電影非常溫馨感人，我很推薦
兩兩相似度：
(1) × (2) = 0.6363
(1) × (3) = 0.5152
(2) × (3) = 0.2989
```

### 第 1 組與第 2 組的差異是否符合預期

- **符合預期**：第 1 組（同談咖啡）的兩兩相似度應**明顯較高**；第 2 組（高鐵／電影／手機各不相干）的相似度應**明顯較低**。這代表語意相近的句子向量方向接近，無關的句子方向分散。

### 其他自定義的測試
- **第 3/4 組在抵抗「偷換概念」這類語意差異上的能力比我想的好**：第 3 組顯示同一個詞「紅茶」在不同語境（飲料 vs 人名）能明顯區別，但第四組一樣的「紅茶」換另一種語境（飲料 vs 功能）的比較就就不能說是顯著的區別，樣本數在這個測試裡太少了，不過整體來說趨勢是分的開的。
- **第 5 組在情緒或句型干擾下還能區分主題**：句 (1) 與 (2) 雖情緒相反但同為餐廳主題，相似度應**高於**它們與不同主題句 (3) 的相似度，顯示 embedding 主要依「主題」而非「情緒」聚類。

# 作業 1：角色聊天機器人 —— 星語 ✦ 療癒系星座占星師

> AI Agent 實作工作坊（JavaScript 版）
> 基底分支：`1.4-openai-api-with-memory`

## 一、角色設定

**星語** 是一位「深夜星空電台的療癒系占星師」。語氣溫柔、療癒、充滿正能量，像深夜電台 DJ 一樣陪聽眾聊心事，用繁體中文回應。

## 二、功能說明

透過 **function calling** 讓 LLM 自行呼叫三個本地工具，提供以下功能：

| 功能 | 說明 | 檔案 |
|---|---|---|
| **記住使用者星座** | 生日 → 推算星座（含跨年摩羯座的邊界處理），存進 profile，跨對話自動帶入 | `lib/zodiac.js`、`db/profile.js` |
| **星座配對分析** | 以四象元素（火土風水）與占星相位（角度距離）計算契合度 | `lib/compatibility.js` |
| **結構化每日運勢** | 以固定排版格式輸出愛情/事業/財運/幸運色/幸運數字/幸運物 | `prompts/system.js` |

### 配對演算法說明（`calcCompatibility`）

1. 以兩星座的**四象元素關係**決定基礎分（火風相生、土水相生、水火相沖…）。
2. 再依兩星座在黃道上的**角度距離**（合相/六分相/四分相/三分相/對分相）微調。
3. 分數鎖在 40~99，且 `a×b === b×a`、同輸入永遠同輸出。

契合度數字由演算法計算，LLM 負責以療癒語氣解析。

## 三、檔案結構

```
main.js                對話主迴圈 + function calling 派發
config.js              讀取 OPENAI_API_KEY
prompts/system.js      療癒系人設 system prompt
lib/zodiac.js          生日 → 星座 本地推算
lib/compatibility.js   四象元素配對演算法
db/messages.js         對話記憶（支援 tool 訊息）
db/profile.js          記住使用者星座
test/local.test.js     本地邏輯測試（離線可跑）
```

## 四、執行方式

```bash
npm install
cp .env.example .env      # 填入你的 OPENAI_API_KEY
npm start
```

離線驗證本地邏輯（不需金鑰）：

```bash
npm test
```

測試涵蓋：星座邊界日期、跨年摩羯座、非法日期、名稱容錯、配對對稱性／可重現性／水火相沖低分。
